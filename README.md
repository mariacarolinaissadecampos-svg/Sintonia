# Sintonia

Aplicativo de cartas sobre narrativas da música pop, desenvolvido como projeto acadêmico de Sociologia da Mídia.

Inclui 25 cartas, identidade visual da parceria com DEEZER e ícone para a tela inicial do celular.

## Executar localmente

Abra `dist/index.html` no navegador ou execute `python3 -m http.server 8000 --directory dist` e acesse http://localhost:8000.

Site publicado: https://sintonia-pop-carolina.poeticnewt133.chatgpt.site
